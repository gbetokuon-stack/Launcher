Tập Trung Vào Những Gì Bạn Thực Sự Cần

Không tính năng thừa thãi, không rác. Mọi công cụ đều hướng đến trải nghiệm chơi mượt và cài mod nhanh.

Tự Tải Mod Phụ Thuộc

Cài một mod bất kỳ, launcher tự tìm và kéo luôn các thư viện bắt buộc (như Fabric API, Cloth Config, Sodium). Không còn cảnh vào game rồi mới văng vì thiếu file.

Auto Dependency Resolver

Cách Ly Bản Chơi (Instance)

Mỗi bản chơi có thư mục mod, save map, config riêng biệt hoàn toàn. Cài thử nghiệm bao nhiêu modpack tùy thích mà không sợ hỏng thế giới sinh tồn cũ.

Thư Mục Sandbox Riêng Biệt

Bắt Lỗi Crash Thông Minh

Game bị văng? Launcher quét log và chỉ đích danh file mod gây lỗi, kèm giải pháp thay vì bắt bạn ngồi đọc mò mẫm hàng nghìn dòng mã lỗi Java.

Smart Crash Inspector

Tối Ưu Cờ JVM & Trị Khựng (Stutter)

Áp dụng chuẩn cờ Aikar's Flags và Shenandoah GC, giúp Java thu dọn bộ nhớ êm ái, triệt tiêu giật khựng khung hình (1% low drops) khi bay hoặc load chunk nhanh.

Zero-Drop Memory GC

Tích Hợp Shader Iris Hiện Đại

Hỗ trợ Complementary, BSL, Solas mượt mà. Đường ống render Vulkan/DirectX giúp shader nạp nhanh gấp 3 lần và tiết kiệm tài nguyên hơn OptiFine cũ.

Iris Shader Pipeline

Microsoft OAuth & Chơi Offline

Đăng nhập bản quyền an toàn qua Microsoft OAuth 2.0 PKCE không lưu mật khẩu. Hỗ trợ tạo tên tài khoản Offline để chơi mạng LAN cùng bạn bè tiện lợi.
